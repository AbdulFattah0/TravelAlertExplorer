# 🌍 TravelAlertExplorer

A full-stack web application that allows users to search international travel advisories, view detailed country alerts, and bookmark destinations for quick access.

## Features

- 🔍 Search travel alerts by country name or country code
- 🌎 View detailed travel advisory information
- ⭐ Bookmark and manage favorite travel alerts
- 🔄 Refresh the travel alerts database
- 📱 Responsive Material UI interface
- ⚡ Fast React frontend powered by Vite
- 🗄️ RESTful API built with Express.js
- 💾 MongoDB database integration


## Installation

```bash
# Client
cd client
npm install
npm run dev

# Server
cd server
npm install
npm run watch
```
